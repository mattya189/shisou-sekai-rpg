# 探索システム

> **状態**: Phase 4〜5 で実装済み。ダンジョン（連戦）は Phase 7。

## 遊びの流れ

```
街 →「街の外へ」→ 行き先を選ぶ → 地点
地点 → 探索コマンド（行動力を使う）→ イベントカード → 選択肢 → 戦闘／採取／発見 → 報酬・仲間加入 → 継続／再戦／装備確認
行動力が尽きたら → 街へ戻る → 宿屋で休む（行動力・HP回復、翌朝になる）
```

## フィールド（`src/exploration/map.js`）

- 自由歩行ではなく、**地点を選んで移動する選択式**。街と地点はノードで、`connections` でつながる。
- 通常の移動は**行動力を使わない**。`distance` ぶんゲーム内時間が進む。
- 接続に `apCost` を書くと、その移動だけ行動力を使う（危険な移動など）。
- 接続に `requires: { flags: [...], items: [...] }` を書くと、条件を満たすまで通れない。
  `lockedHint` は通れないときに表示するヒント。
- 接続は片方向。行き来させたいときは両側に書く。
- 初めて行く場所には「未踏」と表示される（`exploration.discoveredNodes`）。

## 探索行動（`src/exploration/actions.js`）

| 行動 | 行動力 | 時間 | 内容 |
|---|---|---|---|
| 探索する `explore` | 1 | 1 | 地点の `explorationEvents` から重み付き抽選。未定義地点だけ従来の出会いやすさ抽選へフォールバック |
| 採取する `gather` | 1 | 1 | 採取テーブルから1〜2回抽選。品質は天候・地点の補正で上がる |
| モンスターを探す `searchMonsters` | 1 | 1 | 必ずエンカウント |
| 詳しく調べる `investigate` | 2 | 2 | 隠し要素（secrets）を探す。なければ品質が上がりやすい採取を2回 |

- 行動力・時間は `balance.exploration.actions` で調整する。
- 地点で使える行動は地点データの `actions` で指定する。
- 戦闘になりうる行動は、パーティが全員倒れていると実行できない。
- **戦闘そのものでは行動力を使わない**。
- 発生結果は `exploration.pendingEvent` に保存する。カードを解決する前の再入力は拒否し、連打やリロードで行動力・報酬が二重反映されない。

### コマンド式イベントカード

- 通常遭遇は即戦闘にせず、短い状況文と「戦う／様子を見る／逃げる」を表示する。「様子を見る」は敵名とレベルを確認でき、追加の行動力を使わない。
- 採取・宝・小イベント・何もなしは結果をカード表示し、「もう一度探索」または「閉じる」で解決する。
- `strongHint` は地点の `optionalEncounters` を参照し、任意強敵へ「挑戦する／今はやめる」を提示する。
- 戦闘後は通常フィールド戦なら「探索を続ける／再戦／装備確認／戻る」を選べる。勝敗・報酬・HP持ち越しなどの戦闘ルールは従来どおり。
- イベント抽選は既存のseed固定乱数を使うため再現可能。

## 行動力

- 1回の遠征で使う方式。初期 6/6（`balance.actionPoints.initial`）、将来の上限の目安は `cap`（10）。
- 宿屋で休むと全回復（宿代 `balance.inn.cost`）。リアル時間での回復やスタミナ課金はない。

## ゲーム内時間（`src/exploration/time.js`）

- リアル時間とは連動しない。朝 → 昼 → 夕方 → 夜 → 翌日の朝。
- 行動と移動で「tick」が進み、`balance.time.ticksPerPeriod`（仮 3）で次の時間帯になる。
- 宿屋で休むと翌日の朝になる。

## 天候

- 地域（`regions.json`）ごとに天候を持ち、**時間帯が変わるたびに**地域の `weatherTable` から抽選し直す。
- 天候（`weathers.json`）の効果:
  - `encounterRate`: 「探索する」でのエンカウント率に掛かる倍率
  - `qualityBonus`: 採取物の品質補正
- 時間帯・天候は、エンカウント・採取物・隠し要素の出現条件（`when`）に使える。

## 出現条件 `when`（`src/exploration/when.js`）

```json
"when": { "periods": ["night"], "weathers": ["weather_003"], "flags": ["flag_001"], "notFlags": ["flag_002"] }
```

書いた項目をすべて満たすときだけ有効。エンカウントテーブルの行、採取テーブルの行、隠し要素で使える。

## エンカウント（`src/exploration/encounters.js`）

- 敵シンボルは出さない。探索・モンスター捜索のときにエンカウントテーブル（`encounters.json`）から抽選。
- 条件を満たす行だけを重み付きで抽選し、敵のレベルは `[最小, 最大]` から抽選。1回の戦闘の敵は最大3体。
- 例: 変異種 `mon_005` は「夜 かつ 雨・霧・雷雨」のときだけ出る。

### 任意強敵

地点データの `optionalEncounters` に `id`、表示名、説明、`enemies` を登録すると、地点画面に「挑戦する／今はやめる」が表示される。通常エンカウントとは別枠で、断っても探索を継続でき、撃破後も再戦できる。敗北時は既存のフィールド戦敗北処理（街へ帰還・HP1）を使うため、進行不能にならない。個体名での画面分岐は行わない。

## 品質（`src/progression/quality.js`）

`balance.qualities` の `weight` が基本の出やすさ。補正 bonus があると、品質 i（普通=0）の重みが `weight × (1 + bonus × i)` になる。
- 採取: 天候の `qualityBonus` + 地点の `qualityBonus`（「詳しく調べる」はさらに +1）
- ドロップ: 補正なし（仮）

## 戦闘後（`src/game/battleOutcome.js`）

| 結果 | 反映 |
|---|---|
| 勝利 | HPを持ち越し。生き残った味方全員に経験値（全額）、ゴールド、ドロップ（品質抽選）、加入判定 |
| 敗北（全滅） | 最後にいた街へ戻され、編成メンバーのHPが `balance.defeat.hpAfterDefeat`（仮 1）になる |
| 時間切れ | HPを持ち越し。報酬なし（撤退扱い） |

- 経験値 = モンスターの `exp` × (1 + (レベル-1) × `rewards.expLevelScale`)。ゴールドも同様。
- **HPは戦闘後も持ち越す**（宿屋・消耗品で回復）。**MPは戦闘後に全回復**（フィールド戦闘）。
- 図鑑用に「遭遇」「撃破」「撃破数」を記録する。

## モンスターの加入（`src/game/recruit.js`）

```
加入率 = 基礎加入率 + 失敗補正 × これまでの失敗回数
失敗回数が guaranteeAfter 以上なら確定加入。成功したら失敗回数は0に戻る
```

- 判定は倒した敵の**種類ごとに1回**（同じ種類が複数いれば一番高いレベルで判定）。加入したときのレベルはそのレベル。
- 1回の戦闘で加入するのは `balance.recruit.maxPerBattle`（仮 1）体まで。
- 所持済みの種類が加入した場合は、`recruit.duplicateTo` の素材（魂の結晶など）に変わる。
- `recruit.special` があるモンスター（ボス用）は通常の判定をしない（Phase 7）。

## 消耗品（`src/progression/consumables.js`）

所持品画面の「消耗品」から、品質を選んで編成メンバーに使う。効果量に品質の倍率（`effectMultiplier`）がかかる。
倒れたユニット（HP0）にも回復アイテムは使える。
