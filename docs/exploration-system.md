# 探索システム

## 正式なゲームループ

ホーム → 冒険 → 思想世界内の冒険先を直接選択 → 探索コマンド → イベントカード → 選択／3対3のオート戦闘 → 報酬・装備 → 再探索／再戦、が基本です。

- フィールド歩行や地点間移動はありません。
- 冒険先の選択・変更では、スタミナもゲーム内時間も消費しません。
- `connections`、`locationId`、旧 `moveTo()` は旧セーブやデータ参照との互換用に残しています。新しいUI・進行からは使いません。
- 選択中の冒険先は `exploration.adventureId` です。「現在地」ではなく、次の探索処理の対象を表します。

## 冒険先（`src/exploration/map.js`）

`listAdventureDestinations()` は `worldId` ごとに地点を列挙します。将来、思想世界が増えても「思想世界 → 冒険先」の階層を維持できます。

地点の `adventureRequires: { flags, items }` で解放条件、`adventureLockedHint` でヒントを指定できます。省略した地点は最初から選択可能です。`selectAdventure()` は発見記録と選択先だけを更新し、スタミナ・時刻・天候を変えません。

冒険先一覧は、既存データから出現モンスター、採取物、任意強敵、探索スタミナ範囲を表示します。

## 探索行動（`src/exploration/actions.js`）

| 行動 | スタミナ | ゲーム内時間 | 内容 |
|---|---:|---:|---|
| 探索する `explore` | 1 | 1 | `explorationEvents` から重み付き抽選 |
| 採取する `gather` | 1 | 1 | 採取テーブルから1〜2回抽選 |
| モンスターを探す `searchMonsters` | 1 | 1 | 必ずエンカウント |
| 詳しく調べる `investigate` | 2 | 2 | 隠し要素、または品質補正つき採取 |

- コストは `balance.exploration.actions`、使える行動は地点の `actions` で指定します。
- スタミナを消費するのは探索やダンジョン入場など、実際の行動を確定した時だけです。戦闘開始の選択や戦闘そのものでは追加消費しません。
- 戦闘になりうる行動は、編成全員が倒れていると実行できません。
- 結果は `exploration.pendingEvent` に保存します。未解決中の再入力をロジック側で拒否し、連打・リロードによる二重消費と二重報酬を防ぎます。

## スタミナ（`src/exploration/stamina.js`）

- 最大・新規開始値: 300
- 自然回復: 30秒につき1
- 300で停止
- `staminaUpdatedAt`（Unix timeミリ秒）と現在値から回復量を計算するため、ゲームを閉じている間も回復します。
- 回復量は `floor(経過時間 / 30秒)`。30秒未満の端数は基準時刻に残し、次回計算へ持ち越します。
- 満タン中の経過時間は貯金しません。満タンから消費した時点を次の回復基準にします。
- 旧v1セーブはv2へ移行し、旧上限で満タンなら300/300、消費中なら現在値を維持します。欠けた時刻は初回読込時に安全に初期化します。
- 宿屋は既存仕様を維持し、料金を払うとスタミナとHPを全回復して翌朝へ進みます。

画面には `現在値/300` と次の回復までを表示します。満タン時は `MAX` です。

## データ駆動イベントカード

地点の `explorationEvents` へ `encounter` / `gather` / `treasure` / `nothing` / `message` / `choice` / `strongHint` を登録できます。`weight` と `when` でレア度・時間帯・天候・フラグ条件を調整します。

- 遭遇: 「戦う／様子を見る／逃げる」
- 採取・宝・小イベント: 短文と「もう一度探索／閉じる」
- `strongHint`: 同じ地点の `optionalEncounters` を参照し、強敵へ直接挑戦
- 任意強敵は冒険先画面にも常時表示され、歩行や移動操作なしで再挑戦可能

イベント抽選は既存のseed固定乱数を使います。地点名やモンスター名によるUI分岐はしません。

## ゲーム内時間・天候

リアル時間のスタミナ回復とは別です。探索行動でtickが進み、朝 → 昼 → 夕方 → 夜 → 翌朝へ変化します。時間帯が変わるたび地域の天候を再抽選し、出現条件や採取品質へ反映します。冒険先の選択では進みません。

## 戦闘後

通常フィールド戦は「探索を続ける／再戦／装備確認／冒険先一覧へ」から選びます。毎回ホームへ戻しません。勝利時の経験値・ゴールド・品質つきドロップ・加入・図鑑記録、HP持ち越しとMP全回復は既存仕様をそのまま再利用します。

敗北時だけ既存仕様どおりホームへ戻し、編成メンバーのHPを1にします。ダンジョンはHP・MPを持ち越す連戦、撤退、途中再開、踏破記録を維持します。
