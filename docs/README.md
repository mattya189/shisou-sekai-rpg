# 思想世界RPG 概要

## ゲームの中心

- 世界探索、モンスター収集、人間キャラクター収集
- パーティ編成（3体・戦闘は3対3、人間とモンスターを自由に混成）と育成
- 装備・アイテム収集、図鑑、ボス攻略、隠し要素の発見

長い一本道のストーリーを読むより、世界を実際に探索して発見する体験を重視します。

## 世界観（確定している範囲）

人間が実際に抱く具体的な考え・思い・感情・価値観・人間関係をテーマにした、複数の独立した世界が存在します。
例: 「異性と付き合えないことへの逆恨み」「家族と話し合える幸せ」「頑張ったのに誰にも褒めてもらえなかった悔しさ」。

**メインストーリーと主人公の設定は未確定です。** データ上の名前はすべて仮（「（仮）」付き）です。

- **キャラクター**: 人間を表す存在（`chr_`）
- **モンスター**: 人間以外の生物・怪物・異形（`mon_`）。原則として全種類を仲間にできる。同種は1体のみ所有。個体値なし。
  希少種・変異種は別IDで管理する。

## 遊べること（プロトタイプ完成時点）

基本のゲームループが一通り遊べます。

1. ホームの「冒険へ」または下部ナビの「冒険」から、思想世界内の冒険先を直接選ぶ（選択だけでは消費なし）
2. 冒険先で「探索する」「採取する」「モンスターを探す」「詳しく調べる」（スタミナを使う）
3. エンカウントしたら自動戦闘（×1/×2/×3）。勝つと経験値・ゴールド・ドロップ、モンスターが仲間になることも
4. 仲間を編成し、特技の優先順位を調整
5. スタミナは最大300で30秒ごとに1自然回復。宿屋でもスタミナ・HPを全回復できる

- 時間帯（朝・昼・夕方・夜）と地域の天候で、出るモンスターや採取物の品質が変わります
- 街ではショップ（売買）、工房（装備強化・製作）、酒場（噂話）、住民との会話、街の探索ができます
- 編成画面から装備の付け替え、素材を使ったランクアップができます
- 丘を「詳しく調べる」と遺跡の入口への道が開き、入口を調べると鍵が見つかります。
  遺跡は3連戦のダンジョン（HP・MP持ち越し）で、最後にボス（大技の予兆・BREAK・部位・HPで変わる行動）が待っています。
  BREAKさせて腕を壊してから倒すと、ボスが仲間になります
- 図鑑では、出会ったモンスターの情報が「遭遇・撃破・調査（5体撃破）・加入」の段階で開き、
  アイテムは品質ごとの入手状況と入手方法を確認できます
- ブラウザを閉じても進行は保存されます。開発環境ではデバッグパネル（右下の DBG）が使えます
