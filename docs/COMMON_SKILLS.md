# 汎用特技の再利用

新モンスターの特技を作る前に、まず `data/skills.json` の既存汎用特技を確認してください。
本作の特技マスターは以前から全ユニットで共通です。別マスターやモンスター専用コピーは追加しません。
今回の汎用能力には `common: true` を付けていますが、実際の参照・発動は従来の固定ID方式です。

| ID | 名前 | 分類 | 属性 | 発動条件 | 効果 | 再利用想定 |
|---|---|---|---|---|---|---|
| skill_046 | 魔力集中 | 汎用特技 | 属性なし | 通常攻撃時10% | 自身の魔法攻撃+10%、自身の次の3行動 | 魔法型 |
| skill_047 | 暗黒弾 | 汎用特技 | 闇 | 攻撃回数3の倍数 | 敵単体へ魔法攻撃120% | 闇魔法型 |
| skill_048 | 拒絶の構え | 汎用特技 | 属性なし | 敵由来のデバフ付与時20%、同一行動1判定 | 自身の魔法防御+15%、自身の次の3行動 | 防衛型・反応型 |
| skill_050 | 生命吸収 | 汎用特技 | 闇 | 攻撃回数5の倍数 | 単体魔法110%、実ダメージ20%を自身へ回復 | 吸収型 |
| skill_051 | 暗黒波 | 汎用特技 | 闇 | 攻撃回数8の倍数 | 敵全体へ魔法攻撃120% | 全体魔法型 |
| skill_052 | 報復本能 | 汎用パッシブ特技 | 属性なし | 敵由来のデバフ付与時 | 重複しない報復：次にダメージを与える攻撃全体+15%、その攻撃後解除 | 報復型 |

この表は説明用です。倍率・条件・効果の実行元と図鑑の表示元は `data/skills.json`、状態の値は `data/statuses.json` です。
IDは既存の `skill_数字3桁` 規則を使用し、名前変更時もIDは変更・再利用しません。

## 別のモンスターへ追加する方法

モンスター定義の `learnset` に、既存IDとそのモンスターの習得ランク・レベルを書くだけです。

```json
{ "skillId": "skill_047", "rank": 2, "level": 10 }
```

ランクとレベルはAND条件です。戦闘ロジック・特技効果・図鑑用倍率をコピーする必要はありません。
魔力集中・拒絶の構え・報復本能も同じ方法で再利用できます。種族・専用スタックの条件はありません。
使用者の逆引きは既存図鑑の `learnset` 検索で自動更新されます。

報復本能は「習得するパッシブ特技」で、固有 `passives` とは別です。5つのセット枠に含み、
未セットでは発動しません。魔力集中・拒絶の構え・報復本能は即時反応でターン・攻撃回数を増やしません。
コンボ・奥義も従来どおりセット対象です。リフューラの10特技を同時に有効にはしません。

## 今回追加した最小限の共通処理

- `consumeMarker`: 生存対象の実消費を合計し、使用した特技の文脈に保存する。
- `consumedMarkerGainSelfMarker`: 自分の特技の消費通知だけに反応する固有パッシブフック。他者・浄化・単なる減少は通知しない。
- `resourceScaledDamage`: 実消費合計または自身のマーカー量に応じた威力を共通ダメージ計算へ渡す。
- `healFromDamage`: 現在の特技の実ダメージを使い、端数切り捨てで回復する。先行する別コンボ・オーバーキル分は含めない。
- `immediateTrigger.normalAttack`: 通常攻撃後の反応。特技攻撃では判定しない。
- `immediateTrigger.enemyDebuff`: 敵由来で実際に成功した弱体状態の付与・更新を、効果文脈内で対象ごとにまとめて判定する。
  無効・耐性で防いだ状態、味方由来、強化状態、マーカーの増加は含めない。
- `nextAttackDamage` / `untilAttack`: 既存状態配列で保持する次の攻撃だけの補正。全対象・全ヒットへ適用後に解除。
  非攻撃行動・全ミスでは残る。攻撃の前にスナップショットを取り、途中の反応で付いた新状態を誤って消費しない。
- `comboFrom` / `completionEffects` に `comboTiming: "afterSkill"` と `comboCondition` を追加。
  既存の予約・次回攻撃コンボを維持し、元特技の終了後に実消費条件で追加発動できるようにした。

状態の弱体分類は `statusEffects.js` の `isDebuff` で共通化し、必要なら状態定義の `debuff` で指定できます。
新しい効果の説明は `src/codex/abilities.js` が実データから組み立てます。

## リフューラの推奨セット例

侵色供給役と組む場合、☆5・Lv40では `万彩拒絶砲 → 染色捕食 → 色喰らい → 護色反転 → 生命吸収`。
既存どおり上から最初に条件が成立した1特技が行動を使うため、奥義を先頭に置くとほかの倍数特技と競合した際も優先できます。
コンボは染色捕食と護色反転の両方をセットしないと発動しません。
